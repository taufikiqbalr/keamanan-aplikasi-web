# TI215 — Keamanan Aplikasi Web

Portal perkuliahan untuk kelas **TI215 - Keamanan Aplikasi Web (Reguler)**, Program Studi Teknologi Informasi, Institut Teknologi Tangerang Selatan (ITTS).

## Jadwal Kelas

- **Hari:** Rabu
- **Waktu:** 09:45 - 12:00 WIB
- **Ruang:** Lab 2
- **Semester:** 3
- **Bobot:** 3 SKS (2 Teori + 1 Praktikum)
- **Tahun Akademik:** Ganjil 2026/2027

## Isi Portal

Portal ini memuat informasi mata kuliah dan CPMK, class schedule 16 minggu, materi mingguan, short discussion dan hands-on, tugas dan kuis, UTS dan UAS, proyek integratif, referensi belajar, serta kebijakan ethical testing.

## Penilaian

| Komponen | Bobot |
|---|---:|
| UTS | 25% |
| UAS / Proyek Integratif | 35% |
| Tugas Praktik | 15% |
| Kuis & Partisipasi | 15% |
| Presentasi Proyek | 10% |

## UAS — Video Wajib

UAS berbentuk proyek integratif. Mahasiswa **wajib mengumpulkan video penjelasan dan demo proyek berdurasi 10–15 menit**. Untuk proyek kelompok, setiap anggota wajib tampil/berbicara dan menjelaskan kontribusinya.

## Ethical Testing

Seluruh pengujian keamanan hanya boleh dilakukan pada aplikasi laboratorium yang disediakan, sistem milik sendiri, atau target yang memiliki izin eksplisit. Dilarang melakukan pengujian terhadap sistem publik tanpa izin.

## Deploy ke Vercel

Repository ini dibuat sebagai static site dan dapat langsung di-import ke Vercel.

- Framework Preset: **Other**
- Build Command: kosong
- Output Directory: kosong
- Root Directory: ./

File vercel.json sudah menambahkan security headers dasar.

## Development Lokal

Jalankan web server lokal, misalnya:

    python -m http.server 8080

Lalu buka http://localhost:8080
